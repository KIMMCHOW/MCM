# 2026 MCM A 题解题说明（中文）

本文是英文论文 `paper/main.pdf` 的中文导读，帮助快速理解建模思路、核心方程和主要结论。所有数字都来自 `results/*.json`。

## 1. 题目在问什么

建立一个**连续时间**模型，描述手机锂电池的荷电状态 SOC(t)，并据此预测“还能用多久”（Time-to-Empty, TTE）。题目共四问：

1. **连续时间模型**：从最简单的描述出发，逐步加入屏幕、CPU、网络、GPS、后台等因素；数据只能用来支撑参数，不能用纯曲线拟合或黑箱机器学习替代模型。
2. **续航预测**：不同初始电量和使用场景下的 TTE；与实测或合理行为对比；量化不确定性；指出模型哪里准、哪里不准；找出最耗电的因素和“影响意外小”的因素。
3. **敏感性分析**：模型假设、参数取值和使用习惯波动对结果的影响。
4. **建议**：给用户的省电建议、给操作系统的策略、电池老化，以及向其他便携设备推广。

## 2. 建模思路：四层模型，每层只加一种物理机制

| 层级 | 状态变量 | 新增机制 | 能回答什么 |
|---|---|---|---|
| L0 能量桶 | 剩余能量 E | dE/dt = −P(t) | 续航 ≈ 可用能量 / 平均功率；各部件的“能量占比 = 续航弹性” |
| L1 准静态电路 | SOC z | 开路电压 U(z)、串联内阻、**恒功率负载** | 低电量时电压下降 → 电流上升 → 损耗上升；续航的精确积分公式 |
| L2 电-热耦合（主模型） | z, v₁, T | RC 极化、集总热节点、Arrhenius 内阻、熵热、皮肤温度降频、瞬时脉冲导致的欠压关机 | 低温“有电却关机”、游戏发热降频 |
| L3 老化 | 上述 + 三个慢变量 | 日历老化、循环 SEI、析锂；容量下降 + 内阻上升 | 电池健康度 80 % 后的续航与冬季关机 |

为什么分层：每加一层就能单独量化这一机制对续航的影响（结构敏感性分析），也方便写出闭式解，帮助解释结果。

## 3. 核心方程（L2）

- **恒功率负载**：手机的电源管理芯片（PMIC）稳压，所以电池看到的是恒定**功率**，而不是恒定电流。由 P = V·I、V = Ũ − R₀I 解得

  I = 2P / (Ũ + √D)，D = Ũ² − 4R₀P，Ũ = U(z,T) − v₁

  电压下降时电流自动增大；D < 0 表示需求超过电池能输出的最大功率，即电压崩溃。
- **电量守恒**：dz/dt = −I / (3600·Q_max)
- **RC 极化**：dv₁/dt = (R₁I − v₁)/τ₁
- **内阻随温度变化（Arrhenius）**：R₀(z,T) = R₀,ref·[1 + A·e^(−z/z₀)]·exp[(Eₐ/R)(1/T − 1/T_ref)]·(1 + 老化增量)。−20 °C 时内阻约为 25 °C 时的 3.6 倍。
- **热平衡（Bernardi）**：C_th·dT/dt = P + I²R₀ + v₁²/R₁ − I·T·∂U/∂T − (T − T_amb)/R_th
- **降频**：皮肤温度接近 45 °C 时，用 logistic 函数平滑压低 SoC 功率。
- **欠压关机**：亚秒级功率脉冲（射频唤醒、CPU 突发、相机启动）期间，若瞬时电压 V_pk < V_sys（约 3.3 V），手机直接关机。冷天和老化电池的 R₀ 大，所以会在显示还有电时关机。
- **TTE** = 下列事件中最先发生的一个：电量计报 0 %（电压降到 3.40 V）、欠压关机、功率不可行、过热关机。

### 功耗子模型（都来自已发表的测量）

- **屏幕（OLED）**：固定开销 + 面积 × 亮度^γ × 平均画面亮度（APL）+ 高刷新率附加。深色模式靠降低 APL 省电。
- **SoC**：DVFS 下 P = P_max·x·[v₀ + (1 − v₀)x]²，近似三次方，最后 20 % 的性能要花掉 37 % 的功率。
- **射频**：数据突发按泊松过程到达，蜂窝网络有“尾巴”状态（传完数据后还要高功耗等待约 10 s），可以推出时间平均功率的**精确**公式。弱信号会放大射频能耗。
- **GPS、相机、音频、蓝牙**：按开关状态叠加固定增量。

### 随机使用（CTMC）

用户在“空闲 / 社交 / 视频 / 游戏 / 导航 / 视频通话 / 相机 / 音乐”之间切换，建模为连续时间马尔可夫链。电池于是成为分段确定马尔可夫过程，可以推出续航的**均值（Dynkin 公式）和方差（中心极限定理）**，并用蒙特卡洛验证。

## 4. 参数从哪里来

- 参考机 **RP-63**：一台通用的 2024 年款 6.3 英寸手机，电芯 4.70 Ah、4.45 V（LCO/石墨），可用能量 17.8 Wh。它不对应任何具体产品。
- 约 93 个参数，每个都有出处（论文测量、PyBaMM 电化学参数拟合、推导值或标注的假设）和不确定性区间。
- **只有一个标定常数**：用 Bonn 数据集中 iPhone 14 Pro 黑屏待机这一组实验，标定“唤醒开销”0.09 W。其余验证全部是盲测。
- 开放数据：Bonn iPhone 实测（CC BY 4.0）、LG HG2 电芯（CC BY 4.0）、Oxford（ODbL）、PyBaMM Ai2020 参数（BSD-3）。NASA 数据没有明确许可，只用于次要检查。

## 5. 主要结论（对应四问）

### 续航预测（25 °C、新电池、满电起）

| 场景 | 平均功耗 | 续航 |
|---|---|---|
| 待机（Wi-Fi） | 0.040 W | 443 h |
| 阅读 | 0.46 W | 38.9 h |
| 刷社交媒体（Wi-Fi） | 1.06 W | 16.6 h |
| 视频：Wi-Fi / LTE / 5G | 0.55 / 0.69 / 0.84 W | 32.3 / 25.5 / 21.1 h |
| 导航 | 1.49 W | 11.8 h |
| 视频通话：LTE / Wi-Fi | 2.52 / 1.62 W | 6.9 / 10.8 h |
| 3D 游戏：15 / 25 / 35 °C | — | 4.4 / 5.7 / 10.3 h |
| 典型的一天（随机使用） | 0.44 W | 39.6 ± 7.1 h |

### 三种“耗电机制”

1. **常温下是能量问题**：续航 ≈ 可用能量 / 平均功率，误差不到 2 %；内阻的影响可以忽略（弹性 −0.007）。决定续航的是屏幕、SoC 和射频。
2. **低温 + 老化是电压问题**：
   - −20 °C、健康度 80 % 时，户外拍照会让手机在显示 **44 %** 电量时关机（常温新电池可用 27.0 h，此时只有 12.3 h）
   - 刷社交媒体时则在显示 23 % 时关机
   - 滞留的电量回暖后会回来
3. **游戏是散热问题**：降频决定续航。环境越热，降频越早，功耗越低，续航反而越长（35 °C 时 10.3 h），但性能只剩约 52 %。

### 最耗电的和“意外影响小”的

- **最耗电**：
  - 持续高负载游戏：占典型一天能量的 28 %，但贡献 81 % 的续航方差
  - 高亮度、浅色界面、高刷新率的屏幕
  - 蜂窝网络上的视频通话，弱信号时更严重（−110 dBm 时 −23 %）
  - 5G 的“尾巴”功耗
  - 低温 + 老化 + 瞬时脉冲的组合
- **影响意外小**：
  - 后台同步减半只多 0.1–0.4 %，因为现代 4G 的尾巴功耗已经很低
  - 静止状态下的 GPS（实测仅约 +0.03 W）
  - 蓝牙耳机、传感器
  - 常温下的电池内阻和倍率效应
  - 新电池在 −10 °C 下导航只少 3.4 %，因为手机会自己发热
  - 自放电

### 敏感性与不确定性

- 参数不确定性：常温下续航变异系数 0.13–0.21；冷天老化时升到 0.47–0.56。默认参数偏乐观，各场景中位数比名义值短 3–38 %。
- 典型的一天里，**使用习惯的随机性贡献 66 % 的续航方差**（重度用户 74 %），硬件参数贡献其余部分。
- Sobol 全局敏感性显示同样的三种机制：常温时由各部件功耗主导，游戏时由散热参数主导，冷天老化时由内阻、老化导致的内阻增长和脉冲大小主导。
- 结构敏感性：常温下换用不同的电路结构（2RC、KiBaM、恒流负载等），续航变化 ≤ 1 %；冷天老化时，能量桶模型会高估 79 %，必须用完整模型。

### 建议

- **用户**：
  - 少玩 3D 游戏：典型的一天约有 1 小时游戏，不玩可延长 37 %
  - 刷新率限 60 Hz（+4.7 %），用深色模式（+4.6 %）
  - 视频通话改语音，优先用 Wi-Fi
  - 避免弱信号和 5G 待机
  - 冷天给手机保暖
- **操作系统**：
  - **峰值功率调速器**：冷天、老化电池时，按模型算出的安全脉冲上限压低瞬时功率。滞留电量从 23 % 降到 2.4 %，续航 +25 %
  - 温度和健康度感知的电量显示：把 0 % 对应到预测的关机点，并给出带区间的剩余时间，例如“41 h，30–54 h”
  - 合并后台唤醒，例如 5G 待机 +67 %
  - 按需切换 5G / LTE / Wi-Fi，信号弱时推迟大流量传输
  - 自适应刷新率
  - 温控帧率上限，取代被动降频
- **老化**：
  - 每晚充到 100 % 时，约 2.9 年降到 80 % 健康度
  - 80 % 充电上限：2 年后健康度多 1.9 个百分点
  - 35 °C 的炎热气候：2 年后少 12 个百分点
- **推广**：平板、笔记本、手表、耳机、无人机都可以用同一组方程，只换常数；用 5 个无量纲数比较不同设备。

## 6. 验证：哪里准、哪里不准（如实报告）

- **准**：
  - iPhone 待机和相机：误差 −11 %～+6 %
  - iPhone 的厂商续航规格：除蓝牙音频外全部落在 ±25 % 内
  - 25 °C 下与电化学 DFN 模型相差 ≤ 2.4 %
  - Bonn 数据更支持“能量比例 SOC”的定义，与题目词汇表一致
- **不准**：
  - 静止 iPhone 的 GPS：实测几乎不耗电，模型高估
  - Android 机型的亮屏底噪是我们的 1.6–2.9 倍
  - −20 °C 下低估了电芯的容量损失（预先登记的预期；KiBaM 变体能补回大部分）
  - 冷天高倍率时，电化学模型出现传输受限的“崩溃”，等效电路模型表示不了
- 预先登记的 59 条判据通过 31 条。失败项都作为发现写进了论文，没有为了通过而调参。
