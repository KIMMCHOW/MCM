# 2026 MCM A 题：智能手机电池耗电建模

本仓库是 2026 年美国大学生数学建模竞赛（MCM）A 题 *Modeling Smartphone Battery Drain* 的完整解答，包括模型代码、分析脚本、图表和英文论文（MCM 要求英文提交）。

## 题目要点

建立一个**连续时间**数学模型，描述锂离子电池手机在真实使用条件下的荷电状态 SOC(t)，并据此预测**剩余续航时间（Time-to-Empty, TTE）**：

1. **连续时间模型**：从最简单的耗电描述出发，逐步加入屏幕、处理器、网络、GPS、后台任务等因素；
2. **续航预测**：不同初始电量和使用场景下的 TTE，量化不确定性，找出最耗电和影响意外小的因素；
3. **敏感性分析**：模型假设、参数取值、使用习惯波动对预测的影响；
4. **建议**：给用户的省电建议、操作系统的省电策略、电池老化影响，以及向其他便携设备的推广。

论文正文不超过 25 页，需包含一页摘要、目录、参考文献和 AI 使用报告。

## 建模思路

| 层级 | 内容 | 作用 |
|---|---|---|
| L0 | 能量桶模型 dE/dt = −P(t) | 给出闭式续航公式与直观解释 |
| L1 | 加入开路电压 OCV(SOC) 与内阻：恒功率负载下电流随电压变化 | 解释低电量时掉电加速 |
| L2 | 加入 RC 极化、整机集总热模型、温度相关内阻（Arrhenius）与温控降频 | 解释低温突然关机、高负载发热 |
| L3 | 加入电池健康度 SOH（容量衰减 + 内阻增长） | 解释老化后续航下降与“有电却关机” |

- **功耗子模型**：屏幕（亮度、面积、OLED 内容）、SoC（利用率、DVFS）、蜂窝/Wi-Fi（吞吐、信号强度、尾能耗）、GPS、后台与待机功耗，参数均来自已发表的测量文献。
- **使用习惯随机性**：用连续时间马尔可夫链描述用户在各活动之间切换，推导续航均值与方差的近似公式，并用蒙特卡洛验证。
- **验证**：与公开数据集、厂商公布的续航规格以及电化学参考模型（PyBaMM）进行对比。

## 目录结构

```
src/phonebatt/     模型代码（参数、功耗子模型、电-热-老化常微分方程、续航事件检测、批量积分器）
analysis/          各项分析脚本（续航场景、验证、不确定性、敏感性、老化、建议）
results/           分析结果（JSON）
paper/             LaTeX 论文源码与图表（paper/figures/）
docs/research/     参数调研笔记（含文献出处）
docs/design/       模型设计方案与最终规格
```

```bash
# 编译论文
cd paper && latexmk -pdf main.tex
```
